Key differences between HTML, CSS, and Programming

If we think of a website as a building, HTML would be the structural framing, (supporting beams, foundations) that hold everything in place and give the building a basic shape. CSS would be the paint, trim, and interior design elements. CSS makes the frame look like a real building, rather than just the bare studs of one.

Programming however, turns buildings (that may be structurally sound and pretty into something people can actually use. It adds the doors, windows, shutters, stairs, and elevators. And more importantly, the hinges and machinery behind them. Programming determines if a door leads to the kitchen or the basement, or which direction you turn the key opens a door and which way locks it, it determines which buttons in the elevator take you to which floors. Programming is the logic that determines what happens in response to an action that a user does. A program checks a variable value and reacts differently depending on what’s stored there. Just like a central air system might heat a building if it was cold outside or cool it if it was hot outside.

That’s the difference between HTML and CSS and programming. Buildings can have sturdy structures and strong foundations(HTML), with beautiful decor and trim(CSS), but if the doors are all painted shut, the elevators don’t work, and the AC is broken, if the website hasn’t been programmed well, then people can’t really use it.

The main types of programming constructs, as described in the lesson on fundamentals of programming are

  1. Variables (and their values)
  2. IF statements
  3. LOOPS
